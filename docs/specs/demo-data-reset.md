# デモデータの投入と日次リセット — 仕様

Issue #56「デモデータの生成と日次リセット」の仕様である。デモデータを投入する手段、日次で入れ直す手段、そして時刻を持たない稼働実績を含む旧データを破棄する手段を扱う。既存の条文はこれらを「デモデータを扱う Issue」に委ねている（P 節の出典）。本仕様はその受け皿である。

業務ルール・ユビキタス言語は**この仕様へ書き写さない**。正解は各業務仕様と `docs/domain/ubiquitous-language.md` にある。本仕様に書くのは次の5つに限る（ADR 0004）。

- 既に決まっていることの要旨と出典（P 節）
- 人間の決定の記録（Q 節）
- 人間の確認を待つ事項（U 節。2026-10-27 に U-1〜U-7 は人間が決定し、その記録も同節に置く。**同日、U-8・U-9 も人間が決定した**）
- 受け入れ条件（AC 節）
- デモデータの値（「デモデータの値」節）

- **状態**: **Q-1〜Q-8 は 2026-10-27 に人間が決定した。** 同日、**U-1〜U-7 と、Scheduler の再試行をしない設定（AC-11-5）も人間が決定した**。また、**「デモデータの値」節は 2026-10-27 に人間がこの節全体を承認した（【仕様工程】の印の値を含む）**。
  - **U-8（デモの契約以外の契約の行の契約期間）と U-9（リセット用 `cmd` の import の範囲）も、2026-10-27 に人間が決定した。** 同日、**Lambda の非同期呼び出しの再試行を 0 にすること（AC-11-5）**、**`workmonth-implementation-design.md` AC-9-16-a への注記**、**README の ADR 一覧への 0022 の行の追加**、**ADR 0022 の承認**も人間が決定した
  - **人間の決定を待つ U は残っていない。** U に依存する AC（各 AC の「依存」欄に U を記した行）は、いずれも依存が解消した。「依存」欄の U の記録は、決定の出所として残す
  - **2026-10-28、レビュー往復1（PR #144）の指摘について人間が次の3点を決定した。** ①リセット用 Lambda の timeout を 60 秒にする（AC-12-12。既存の3本の Lambda の timeout は #56 の範囲に入れない＝AC-13-11）。②DDL の型が本番の既存テーブルと合うかを、初回デプロイの前に人が確かめる（AC-3-6-a・AC-13-12）。③AC-9-1・AC-9-5 のうち観測できない部分を、レビューで担保するものとして AC-14-7 に足す（要求は緩めない）
- **日付**: 2026-10-27（仕様工程が起草し、同日の人間の決定を反映した）。**2026-10-28 に、同日の人間の決定（上の①〜③）を反映した**
- **決定者**: Q 節と U-1〜U-7 の決定は人間（2026-10-27 に AskUserQuestion で明示選択）。**U-8・U-9 と、Lambda の非同期呼び出しの再試行を 0 にすること（AC-11-5）も人間（2026-10-27 に AskUserQuestion で明示選択。main セッション経由で受領）**。**2026-10-28 の①〜③（AC-12-12・AC-13-11・AC-3-6-a・AC-13-12・AC-14-7 の追記）も人間（2026-10-28 に AskUserQuestion で明示選択。main セッション経由で受領）。ただし各行で「仕様工程の定め」と印を付けた細部は人間の決定ではない**。AC 節と「デモデータの値」節で「**仕様工程の定め**」と印を付けた行は、仕様工程が定めたものであり、**人間の決定ではない**。覆すのに人間の承認は要らないが、仕様の改訂として扱う。**ただし「デモデータの値」節の【仕様工程】の値は、2026-10-27 に人間が節全体を承認したため、確定した値として扱う**（印は値の出所の記録として残す）

## 決定（Q）— 2026-10-27 人間が決定

### V-7. 掛け持ちの2契約の重なり

**既存仕様の確認**:

- 時刻の妥当性（`daily-record-entry.md` AC-3）は、1つの稼働実績の中の前後関係と休憩の位置だけを扱う
- 1日1レコード（同 D-1・AC-2-2）は、**同一勤務月内**の対象日の一意性である
- 勤務月は `契約 × 年月` で一意である（ユビキタス言語「勤務月の同一性」）

以上から、**契約をまたいで同じ日の時刻が重なることを扱う条文は無い**（禁止も許可もしていない）。検査もされない。
