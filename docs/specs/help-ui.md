# ヘルプ — UI/画面 仕様

ADR 0021 決定1 が加えた閲覧系の画面「ヘルプ」の UI/画面 受け入れ条件。ヘルプは、勤務月の流れ・稼働実績の入力・精算幅と超過／不足を、全ロール（ゲストを含む）へ説明する画面である。

この仕様は**業務ルールの正解ではない**ものとする。ヘルプの本文は業務ルールを利用者向けに言い換えて示すが、ルールの正解は各業務仕様と `docs/domain/ubiquitous-language.md` が持つ。本仕様は「どの事柄を、どの条文に基づいて説明するか」と「画面の形」だけを定め、ルールの値を本仕様の正解として持たない（ADR 0004）。出典の条文が改まったら、ヘルプの文言は出典に合わせて改める。

- **決定者**: 人間（プロジェクトオーナー）。画面があること・対象のロール・説明する3つの事柄は人間決定（ADR 0021 決定1）。本文の文言・画面の構成は AI 起案であり、2026-10-13 に人間が承認した
- **日付**: 2026-10-10（2026-10-13 改定: 語の確定と、開けない画面から既定の画面へ移す人間決定（`login-ui.md` AC-6-7〜6-9-b）を反映。同日の人間決定により、AI 起案の箇所をすべて人間の承認済みへ改めた）
- **前提 ADR**: 0021（閲覧系の画面）／0016（認証・ロール・ゲスト）／0015（デザイン工程）
- **AI 起案の扱い**: 条文中に「AI 起案（2026-10-13 に人間が承認）」と書いた箇所は、AI が起案し、2026-10-13 に人間が一括で承認したものである。承認済みであり、その箇所をテストの期待値にしてよい

## スコープ

- **対象**: ヘルプ画面の本文（説明する事柄・文言の案・出典）、画面の構成、開ける利用者、状態を変えないこと
- **非対象**:
  - サイドバーの項目とヘルプへの導線（`work-month-listing-ui.md` AC-10 が持つ。本仕様で重ねて定めない）
  - ヘッダーの構成（`login-ui.md` AC-9 が持つ）
  - 業務ルールそのもの（各業務仕様とユビキタス言語が持つ）
  - 稼働の推移で使う語（「確定した月」「入力中」「精算幅に収まった月」）の説明。語は 2026-10-10 に人間が確定した（ユビキタス言語「稼働の推移で使う語」）が、ADR 0021 決定1 がヘルプに挙げる事柄に含まれない
  - デザイントークン・具体レイアウト（`design-system.md`）

### AC-3. 説明する事柄と文言の案

各行は「伝える事柄」と、その正解を持つ「出典」を対にする。文言の案は AI 起案（2026-10-13 に人間が承認）である。ハンドオフ（`design/handoff/2026-10-theme-b/Help.dc.html`。記録であって正ではない）の文言を下敷きにし、出典の条文と食い違う箇所・出典の無い値を外した。

承認された後のテストは、各行の文言が本文に出ることを読む。出典の条文が改まったときは、文言を出典に合わせて改め、本表を更新する（ルールの正解は出典が持つ）。

文言の案は、時刻の語（開始時刻・終了時刻・休憩など）にユビキタス言語「稼働時間の算出に使う時刻」の語（2026-10-10 に人間が確定）を使う。語が改まったら文言も改める。

| # | 伝える事柄 | 文言の案 | 出典 |
