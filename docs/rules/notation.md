# 表記ルール

セッション上のエージェント回答の言語と、docs 内の図の記法を定める。決定の根拠は `docs/adr/0010-harness-engineering.md` §G にあり、なぜそう決めたか（応答言語を分ける理由・既存を据え置く理由）はそちらを見る。ここには規約本文だけを置き、理由は書き写さない（ADR 0004）。

## 応答は日本語に統一する

- **セッション上のエージェント回答（会話・ターミナル出力）を日本語に統一する。**
- これは **docs の記述言語の規則ではなく、応答の振る舞いの規則**である。docs は既にすべて日本語であり、それとは別に「エージェントが人へ返す応答の言語」を対象として定める。両者を混同しない。

## 図は mermaid 記法で書く

- **今後書く docs の図は mermaid 記法で書く。**
- この規則は **今後書く docs にのみ適用し、既存 ADR / docs は据え置く**。既存の図（ASCII アート）を mermaid へ書き換えない。
- 据え置く理由は、既存 ADR の書き換えが **ADR 0001 運用ルール3「ADR は書き換えず、追記もしない」** に抵触するため。当面 ASCII と mermaid が混在するが、既存 ADR の不可変性を優先する（許容する）。

## 機械検査の限界

- 応答が実際に日本語か、新規 docs の図が実際に mermaid かは**機械検査しない**。応答は振る舞いで CI に痕跡が残らず、「新規かどうか」も既存との混在を許すため機械が判定できない。担保はこの明文化と、それを読むエージェントの遵守に留まる（限界の固定は `docs/specs/notation-rules.md` AC-5）。
