# デザインのハンドオフ（記録）

このディレクトリは、Claude Design で作ったデザインのハンドオフを**特定時点の記録**として残す場所である。

- **正（現況）の持ち主は `docs/specs/` である。** トークン・部品の契約・画面の受け入れ条件は `docs/specs/design-system.md` と各 `*-ui.md` が持つ。ここにある値や画面が仕様と食い違うときは、仕様が正しい。
- ここは `docs/` の外に置く（`docs/rules/development-process.md`「`docs/design/` は作らない」）。成果物をリポジトリに残す方針は ADR 0015。
- ハンドオフの中身は書き換えない。仕様へ取り込む過程で採らなかった点・変えた点は、取り込んだ仕様の側に記録する。
